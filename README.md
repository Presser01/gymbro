# GymBro – weboldal (ideiglenes)

A GymBro edzésnapló app bemutató oldala, adatvédelmi tájékoztatója és webes
nézete (a titkosított mentés a böngészőben nyílik ki). Ez a tároló csak a
weboldalt tartalmazza; automatikusan készül az app tárolójából
(`tools/publish_site.py`), ezért itt ne szerkeszd.

Harmadik féltől származó részek: Barlow és Caveat betűtípus (SIL OFL 1.1,
`assets/fonts`), @noble/hashes és @noble/ciphers (MIT, `app/vendor`), Material
ikonok (Apache-2.0).
